## 📋 Resumen del Proyecto

Este MVP demuestra la construcción de un **Registro de Lotes de Producción** usando smart wallets de Stellar:

1. **Smart Wallet** - Wallet basada en contratos con autenticación Passkey
2. **Registro de Lotes** - Almacenamiento en blockchain para metadata de lotes de producción
3. **Frontend** - Interfaz Next.js para gestión de wallet y lotes

Ver [WALLET_EXPLANATION.md](./WALLET_EXPLANATION.md) para detalles completos.
